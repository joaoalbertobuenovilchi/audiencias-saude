Este sistema ainda não foi conectado a um backend. Preencha as credenciais do seu projeto Firebase no objeto firebaseConfig, logo no início do <script>, e abra o arquivo novamente.
No console do Firebase → Firestore Database → Regras, acrescente o bloco abaixo dentro de match /databases/{database}/documents { … }, junto das regras que já existem (não apague as outras), e clique em Publicar. Depois recarregue esta página.
